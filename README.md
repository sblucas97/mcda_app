## MCDA App

### Requirements
1. python3

### Instructions
1. Clone repository
2. Make sure you are in the app directory
```bash
$ cd mcda_app
```
3. (not required) Create a virtual environment
```bash
$ python3 -m venv venv
$ source venv/bin/activate
``` 
4. Install dependencies
```bash
$ pip3 install -r requirements.txt
```
5. Start applications
```bash
$ python3 main.py
```
